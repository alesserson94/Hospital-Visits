# Project Overview
This project analyzes the visits of patients in a hospital throughout 2025.

# Questions to Answer
1. Analyze the relationship between department and total charge. Does that depend mostly on volume, or cost per stay?
2. Identify seasonal admission trends, and determine year-round staffing based on the time of year.
3. Which insurance provider carries the longest average length of stay (in days)?
4. Are there meaningful differences in the cost per stay between insured patients vs. non-insured patients (who pay out-of-pocket)?

# Tech Stack Used
1. MySQL (JOINs, CASE statements)
2. Python (pandas)
3. Microsoft Excel
